Integración de IA con Nitro

Asistente inteligente

Potencia Nitro con capacidades avanzadas de IA para responder consultas, analizar datos y automatizar tareas.

Mayor productividad

Reduce el tiempo de búsqueda de información y automatiza tareas repetitivas para que los equipos se enfoquen en lo importante.

Propuesta de valor

Integrar capacidades de IA avanzada en Nitro para transformar la forma en que los usuarios interactúan con la información empresarial, mejorando la eficiencia y la toma de decisiones.

¿Por qué integrar IA en este momento estratégico?

Crecimiento exponencial de datos

Aumento exponencial en la información y necesidad de respuestas contextuales en tiempo real.

Automatización inteligente

Los agentes inteligentes permiten automatizar tareas, consultar datos empresariales de forma natural y generar contenido útil.

Ventaja competitiva

Fortalece la competitividad al liberar recursos humanos y mejorar la velocidad de decisión.

Tendencia global

Se alinea con una tendencia global: asistentes contextuales empresariales (Copilots) están revolucionando la productividad.

¿Dónde estamos hoy?

Plataforma funcional

Desarrollada en Python con LangGraph para flujos conversacionales y Prefect para orquestación de tareas.

Comunicación e interfaz

La aplicación se comunica mediante API y tiene una interfaz visual funcional para pruebas.

Agentes especializados

  • Elastic/RAG: recuperación de información
  • Pandas Agent: análisis de datos tabulares
  • Redmine Agent: conexión a sistemas de gestión
  • JS Agent: ejecución de snippets de código y visuales

Diseño modular

Cada agente es intercambiable, lo que permite escalar o cambiar componentes sin impacto mayor.

¿Cómo se integrará con Nitro?

Paso 1

Nitro realiza solicitud HTTP autenticada con token

Paso 2

IA recibe petición y dispara workflow de Prefect

Paso 3

Agentes consultan fuentes de datos validadas

Paso 5

Nitro integra respuesta en frontend o la reutiliza

Paso 4

Se genera respuesta estructurada (texto, tabla, visual)

Casos de uso de alto valor

Consulta de información sensible

Sueldos, performance, contratos → el sistema solo responde si el token del usuario lo permite.

Visualizaciones comerciales

Nitro pide "ventas por región" y el agente Pandas construye la visualización automáticamente.

Redacción automática

Resumen de incidentes de Redmine, redacción de comunicaciones internas y reportes.

Ejemplo práctico

Un gerente solicita: "Muéstrame el rendimiento de ventas del último trimestre por región y genera un informe ejecutivo". El sistema:

  1. Verifica permisos del usuario mediante su token
  2. Consulta datos de ventas en sistemas autorizados
  3. Genera visualización con el agente Pandas
  4. Redacta informe ejecutivo con conclusiones clave
  5. Devuelve todo en formato estructurado a Nitro

Máxima seguridad y control de acceso

Autenticación robusta

Cada solicitud se acompaña de un token JWT con la identidad del usuario.

Delegación de permisos

La IA no maneja permisos directamente: confía en que Nitro ya filtró los datos o las vistas.

Acceso centralizado

Si se necesita acceso a datos sensibles, la lógica está centralizada en un API Gateway o en Nitro.

Prevención de fugas

Se evitan fugas de información al operar siempre sobre recursos ya autorizados.

    async function consultarAsistenteIA(pregunta, contexto) {
    try {
        const respuesta = await fetch('https://api-ia.empresa.com/procesar_query', {
        method: 'POST',
        headers: {
            'Content-Type': 'application/json',
            'Authorization': `Bearer ${obtenerTokenUsuario()}`
        },
        body: JSON.stringify({
            query: pregunta,
            context: contexto,
            user_id: obtenerIdUsuario()
        })
        });
        
        return await respuesta.json();
    } catch (error) {
        console.error('Error al consultar asistente IA:', error);
        return { error: 'No se pudo procesar la consulta' };
    }
    }

Preguntas frecuentes

¿Cómo se garantiza la seguridad de la información?

El sistema hereda los permisos de Nitro y solo accede a información que el usuario ya tiene autorizada. Además, todas las comunicaciones están cifradas y se mantiene un registro detallado de accesos.

¿Qué sucede si la IA no puede responder una consulta?

El sistema está diseñado para reconocer sus limitaciones. Cuando no puede responder con confianza, lo indica claramente y sugiere alternativas, como contactar a un especialista o consultar fuentes específicas.

¿Cómo se mantiene actualizada la información?

Implementamos un proceso de actualización periódica que reindexará automáticamente las fuentes de datos. Además, se pueden programar actualizaciones manuales para contenido crítico que requiera disponibilidad inmediata.

¿Qué modelos de IA se utilizan?

La arquitectura es agnóstica al modelo, lo que nos permite utilizar diferentes LLMs según las necesidades. Actualmente trabajamos con modelos de Google para el razonamiento general y modelos especializados para tareas específicas como análisis de datos o procesamiento de documentos.
